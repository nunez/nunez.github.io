Privacy Policy

Solana — personal home agent. Last updated: October 15, 2026.

Who we are

Solana is a personal, self-hosted assistant operated by Steven Nunez ("the owner"). It serves exactly one user — the owner — and runs on the owner's own hardware at home. There are no other users, accounts, or visitors to the service itself.

What data it accesses

  • Google Calendar data: events, calendars, and event details the agent reads or writes while acting on the owner's behalf, under the owner's own OAuth grant for the https://www.googleapis.com/auth/calendar scope.
  • Basic account info: the owner's email address and profile name, used solely to identify the account for the grant.
  • Agent conversation logs: messages between the owner and the agent, stored locally on the owner's server so the assistant can remember context.
  • Media the owner sends (e.g. photos on a messaging channel), stored locally on the owner's server.

How the data is used

  • Creating, updating, summarizing, and reminding about calendar events.
  • Producing personal briefings, schedules, and home automations.
  • Improving the assistant's memory of the owner's stated preferences.

Data is never used for advertising, profiling, or third-party analytics of any kind.

Where the data is processed and stored

Processing and storage happen on the owner's local server inside the owner's home. The only network calls made with this data are to Google's own APIs to complete the requested calendar operations, and to the messaging transport the owner uses to talk to the assistant. No other cloud services receive the data.

Sharing

The owner's data is not sold, rented, or shared with third parties. It is not disclosed to law enforcement except as compelled by law directed at the owner personally, which the owner handles personally.

Retention and deletion

Calendar data lives in Google under the owner's account. Local copies (conversations, logs, media) live on the owner's server and can be deleted at any time by the owner. The OAuth grant — and with it all API access — can be revoked instantly at myaccount.google.com/permissions. Revoking the grant stops all access immediately.

This website

These informational pages are static HTML. They set no cookies, run no JavaScript, and load no third-party trackers. Visiting them reveals only ordinary, anonymous web-server log entries (timestamp, requested page) held by the site host.
